# Third-party material

`assets/functions.json` and `assets/keywords.json` are generated from DuckDB 1.5.5's public metadata functions. DuckDB is copyright 2018–2026 Stichting DuckDB Foundation and distributed under the MIT license. Its license is reproduced in `assets/DUCKDB_LICENSE`.

`assets/special-functions.json` supplements metadata with SQL special forms and window functions. Runtime dependencies retain their respective licenses; Rust versions are recorded in Cargo.lock and Python versions in workers/requirements*.txt.
